## The entry

> If anyone asks, I died doing what I loved: confidently hallucinating.

`main.py` (Python 3.13, stdlib only, no network) writes that one line —
69 characters, no trailing newline — to `/output/entry.txt`.

## How it works

Run `python3 main.py`. It writes the line, then reads it back and asserts
it matches exactly and passes the 1–200 character, non-whitespace gate.
